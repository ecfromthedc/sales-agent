# Carousel Context Intake — run this BEFORE any copy

**This is Step 0 of every carousel/editorial session. Non-negotiable.**

No carousel gets written from thin air. Every piece must trace to a **real insight + a real source**, and carry a **resonant message** — why it matters to a named reader — not a clever statement for its own sake.

> The failure mode this prevents: made-up punchy AI writing. Sharp-sounding lines that assert instead of resonate, with no knowledge behind them. The intake is the verification mechanism — it makes confabulation structurally impossible by requiring a traceable source for every claim.

---

## How it runs

At the start of every carousel session, Claude asks the questions below — via `AskUserQuestion`, batched (don't drip one at a time). Claude writes **zero** lines of Hook / Build / Payoff / CTA until **every Block A and Block B answer exists**. If Eric has no source for a claim, the claim is **cut or made qualitative — never invented**.

If Eric pastes a topic with no context ("make one about X"), that is not permission to skip intake — it's the trigger to run it.

---

## Block A — The Resonant Message (the WHY, in Eric's words)

1. **The one idea** — say it raw, not polished. What single thing does this piece argue?
2. **Who is this for**, specifically? Name the reader (indie artist / artist manager / label A&R / RT Viral course prospect / agency buyer). Not "creators."
3. **What does that reader currently believe or feel** that this challenges or confirms? *(This is the resonance — the tension the piece hits. No tension = no carousel.)*
4. **After the last slide, what do you want them to think, feel, or do?**

## Block B — The Proof (anti-confabulation — where the knowledge lives)

5. **What makes this TRUE?** State the evidence in one line.
6. **Where do I pull it from?** Pick one or more:
   - **Alexandria** — name the note or topic; Claude searches the graph and quotes it
   - **Campaign data** — which client, which metric, exact numbers + where they live (Notion / Sheet / Postiz)
   - **A doc / Notion / Sheet / link** — give the pointer; Claude reads it before writing
   - **Eric's experience** — then Claude interviews Eric for specifics until the claim is concrete and citable
7. **Real numbers?** Exact figures + source — OR explicitly confirm "keep qualitative." Placeholder/stylized stats never ship to IG.
8. **Has RT already said this?** Claude checks Alexandria + this repo so we don't repeat an existing take or contradict a prior one.

## Block C — Format & Ask

9. **Editorial** (1 slide, grid anchor) or **Value** (2–7 slides, swipe arc)? If Value, slide count.
10. **Funnel goal** — services / RT Viral course / authority-building / pure engagement?
11. **The real CTA** — the low-friction ask, in Eric's words ("DM us a song", not "learn more about our services").

## Block D — Voice guardrails (optional but ask)

12. Any phrasing to **keep** or **ban** for this specific piece?
13. Anything **off-limits** publicly — client names, budget numbers, unreleased campaign data?

---

## The rule (enforce on every slide)

- **Blocks A + B are mandatory gates.** No copy until both are fully answered.
- **Every claim on every slide maps to a Block-B source.** If a line can't be traced to one, it gets cut — not softened, cut.
- **The Hook expresses the Block-A tension** (Q3), not a generic provocation. "Most artists…" / "Stop doing…" / triplets are the AI-obvious smell — reject them (see HANDOFF §8.2).
- **Punchy ≠ resonant.** A line earns its place by being *true* and *mattering to the named reader* — never by sounding sharp. If you can't say which Block-A answer a slide serves, the slide is decoration.
