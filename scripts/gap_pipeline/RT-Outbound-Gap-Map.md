# Rising Tides — Outbound Gap Map (June 2026)

**What this is:** A map of the labels, management companies, and peer artists in RT's
exact sweet spot that we are **not** servicing yet — built by crossing our live CRM
(630 rows) against Chartmetric's peer-graph around our 271 active client artists, then
filtering to the artists with real budgets, momentum, and release timing that makes
outreach land. Every target includes a pointed contact path so outreach is precise.

---

## TL;DR — the one strategic finding

**RT is dangerously concentrated on Warner/Atlantic.** Of ~230 real-label client rows,
**135 are Warner (86) + Atlantic (49)** — ~60%. Nettwerk (12) is the only other
double-digit relationship. Everything else is a thin tail.

That's both a strength (deep major relationships to mine) and a risk (one A&R reorg at
Warner dents the pipeline). **The outbound gap is structural diversification**, and it
splits two ways:

1. **Warm, under-mined rosters** — labels we already run campaigns for that have
   sweet-spot artists we've never touched. *Fastest money. Warm intro already exists.*
2. **A fragmented long tail of indie labels + manager-led artists** in our lanes
   (indie-folk, country/Americana, alt-pop, EDM) — no single dominant label to chase,
   but a repeatable set of A&R/management contacts to build relationships with.

3. **Established-artist / label-expansion (Tier D)** — we're deep on Warner (135 client
   rows) but a rounding error at **UMG (5 rows) and Sony (10 rows)**, despite **37 and 25
   established artists** respectively sitting in our peer graph. Landing one established
   artist opens a thin major. *This is the biggest business-development lever in the map.*

There is **no single "big label we're missing."** The play is a systematic sweep of the
peer graph — emerging artists for volume, established artists for label relationships —
timed to releases. Exactly what Henry is built to run on a weekly cron.

## Methodology & honest caveats

- **Engine:** For each active client artist, pulled Chartmetric `relatedartists` → the
  peer graph. Artists appearing as peers of many of our clients are, by construction, in
  RT's exact lane. Subtracted everyone already in the CRM → 3,671 true gaps. Enriched the
  top 260 by peer-frequency with monthly listeners, label, career stage/trend, and
  release dates; scored against Henry's rubric with a **hard 8K–600K ML sweet-spot gate**.
- **Sample bias:** Only the top 260 peers were enriched (Chartmetric credits are
  metered). More enrichment = more sweet-spot targets and denser label counts. This is a
  strong first sweep, not the full 3,671.
- **Contacts:** Found via web search (artist sites, bookingagentinfo, label sites,
  LinkedIn). **Verify before sending.** Nothing fabricated — "research contact" / "not
  found" where unconfirmed. Perplexity was down (bad API key); used WebSearch instead.
- **Label canonicalization:** Major backends (sme→Sony, wmg→Warner, Island/Capitol→UMG)
  folded into parents so we don't mis-flag a major as a "gap." Big Loud Texas was caught
  by the web layer as a warm relationship Chartmetric's release label had obscured.
- **No invented metrics.** Outreach uses only RT's real, profile-sourced proof points.
